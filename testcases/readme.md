I selected Katalon Studio as the primary automation tool because it supports both web and mobile testing within a single framework, making it suitable for testing WeMineOffice and the WeMine mobile application.

The main reasons for my choice are:

Cross-platform testing: Supports testing web, mobile, and workflows connecting both platforms.
Reusability: Reusable keywords reduce code duplication and simplify maintenance.
Test management: Test cases and test suites can be organized by application flow and execution priority.
Integration testing: Supports validating workflows such as configuring an Equipment Inspection form on the web and accessing it through the mobile application.

For Manual Test, I use Microsoft Excel to document test cases, including preconditions, test steps, expected results, and execution status. Test cases are organized by flow and platform to improve readability, coverage tracking, and review.
