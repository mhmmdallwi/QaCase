# Test Suites

- **Sign In Regression** — WeMine Mobile username, Microsoft handoff, profile/master sync, first-sync prompt, and network cases.
- **Sign In Web Regression** — the corresponding WeMineOffice Web cases, maintained separately from mobile.
- **Form Builder** — WeMineOffice field types and limits.
- **Equipment Inspection** — feature cases whose platform must be confirmed against the product.
- **Hazard and Follow-up** — WeMine Mobile hazard report, follow-up resolution, and notification checks.
- **Offline and Sync** — sign-in network resilience and mobile hazard synchronization scenarios.
- **Offline Web** — cached-page behavior when WeMineOffice loses network access.

The suites use test data from the test environment. Configure the environment variables in `README.md` and check the test case preconditions before running.
